# Roadmap

GradForge is developed through 20 phases, with six accepted engineering cycles per phase. The current phase is Phase 1, scalar reverse-mode autodiff foundations.

1. Scalar autodiff foundations
2. NumPy tensor core
3. Broadcasting-aware backward passes
4. Linear algebra operations
5. Numerical stability
6. Module and parameter system
7. Core layers
8. Loss functions
9. Optimizers
10. Initialization
11. Training engine
12. Regularization
13. Normalization
14. Gradient verification framework
15. Real data pipeline
16. Neural-network experiments
17. Gradient Inspector
18. Performance profiling
19. Performance engineering and PyTorch validation
20. Final capstone audit

Progress is accepted only when implementation, tests, validation, and documentation support the claimed improvement.
